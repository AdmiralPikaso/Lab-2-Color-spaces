# Цветовые пространства — лабораторная работа

Приложение на C# и Windows Forms выполняет три задания: два варианта перевода RGB в оттенки серого и их сравнение, выделение каналов R/G/B с гистограммами, а также изменение изображения через модель HSV с сохранением результата.

## Запуск

Нужны Windows и установленный .NET 8 с поддержкой Windows Forms.

```powershell
cd 'D:\Юфушка\Компьютерная графика\Lab 2-Color spaces'
dotnet run --project Lab2.csproj
```

В приложении нажмите **«Открыть изображение»** и выберите PNG, JPEG, BMP, GIF или TIFF. Исходный файл после загрузки не остаётся заблокированным. Прозрачные пиксели перед расчётами накладываются на белый фон. При повторном открытии старые результаты освобождаются.

> Если `dotnet build` сообщает, что `Lab2.exe` или `Lab2.dll` занят другим процессом, сначала закройте запущенную копию приложения.

## Задание 1 — оттенки серого

Вкладка **«1. Оттенки серого»** показывает оригинал, два полутоновых результата и их абсолютную попиксельную разность. Коэффициенты приведены на слайде 44 презентации «Цветовые модели.pdf»:

```text
PAL/NTSC: Y₁ = 0,299R + 0,587G + 0,114B
HDTV:     Y₂ = 0,2126R + 0,7152G + 0,0722B
Разность: D = |round(Y₁) − round(Y₂)|
```

Каждое значение округляется до целого числа от 0 до 255 и записывается во все три канала результирующего пикселя: `(Y,Y,Y)`. Вкладка **«1. Гистограммы»** показывает, сколько пикселей имеют каждую интенсивность после первого и второго преобразования. Чёрный столбец изображения разности означает совпадение результатов; более светлый — большую разницу.

## Задание 2 — каналы R, G, B

Вкладка **«2. Каналы R, G, B»** показывает три **полутоновые визуализации** каналов. Для исходного пикселя `(r,g,b)` получаются `(r,r,r)`, `(g,g,g)` и `(b,b,b)`. Поэтому пиксель с максимальным значением выбранного канала на его изображении белый, с нулевым — чёрный. Это не цветные изображения вида `(r,0,0)`, `(0,g,0)`, `(0,0,b)`.

Вкладка **«2. Гистограммы каналов»** содержит три графика частот исходных значений R, G и B от 0 до 255. Цвет линии графика обозначает канал; сумма частот каждого графика равна числу пикселей изображения.

## Задание 3 — HSV

Вкладка **«3. HSV»** показывает оригинал и результат. Ползунки меняют:

- **H — оттенок:** сдвиг от −180° до +180° с циклическим переходом через 0°/360°;
- **S — насыщенность:** от −100% до +100%; отрицательное значение уменьшает текущую насыщенность, положительное приближает её к максимуму;
- **V — значение яркости в модели HSV:** от −100% до +100%; отрицательное значение затемняет, положительное приближает V к максимуму.

При нулевых ползунках результат должен совпадать с оригиналом. Кнопка **«Сбросить»** возвращает все ползунки к нулю. Для каждого пикселя программа выполняет `RGB → HSV`, меняет H/S/V, затем делает `HSV → RGB`. Предпросмотр и сохранённый PNG содержат уже RGB-пиксели.

## Сохранение

В верхнем списке **«Сохранить»** выберите один из семи результатов: PAL/NTSC, HDTV, разность, канал R, G, B или HSV-результат. Нажмите **«Сохранить результат»** и укажите путь. Формат сохранения — PNG. Исходный файл не перезаписывается автоматически.
