# Цветовые пространства — задание 1

Приложение Windows Forms для преобразования RGB-изображения в оттенки серого.

## Запуск

```powershell
cd 'D:\Юфушка\Компьютерная графика\Lab 2-Color spaces'
dotnet run
```

Откройте PNG/JPEG/BMP/GIF/TIFF. Вкладка «Изображения» показывает оригинал, два полутоновых результата и абсолютную попиксельную разность. Вкладка «Гистограммы» показывает число пикселей для интенсивностей 0–255. Кнопка «Сохранить результат» сохраняет выбранное изображение в PNG.

Формулы со слайда 44 презентации «Цветовые модели.pdf»:

- PAL/NTSC: `Y = 0.299R + 0.587G + 0.114B`;
- HDTV: `Y = 0.2126R + 0.7152G + 0.0722B`.

Значение округляется до ближайшего целого. Разность вычисляется как `|Y_PAL/NTSC - Y_HDTV|` после округления. Прозрачные пиксели перед расчётом накладываются на белый фон.
