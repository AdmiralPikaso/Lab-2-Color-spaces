# Цветовые пространства — задания 1 и 2

Приложение Windows Forms: преобразование RGB-изображения в оттенки серого и выделение каналов R, G, B.

## Запуск

```powershell
cd 'D:\Юфушка\Компьютерная графика\Lab 2-Color spaces'
dotnet run
```

Откройте PNG/JPEG/BMP/GIF/TIFF. Вкладка «1. Оттенки серого» показывает оригинал, два полутоновых результата и абсолютную попиксельную разность. Вкладка «1. Гистограммы» показывает число пикселей для интенсивностей 0–255. Кнопка «Сохранить результат» сохраняет выбранное изображение в PNG.

Формулы со слайда 44 презентации «Цветовые модели.pdf»:

- PAL/NTSC: `Y = 0.299R + 0.587G + 0.114B`;
- HDTV: `Y = 0.2126R + 0.7152G + 0.0722B`.

Значение округляется до ближайшего целого. Разность вычисляется как `|Y_PAL/NTSC - Y_HDTV|` после округления. Прозрачные пиксели перед расчётом накладываются на белый фон.

## Задание 2 — каналы R, G, B

Вкладка «2. Каналы R, G, B» показывает оригинал и три полутоновых изображения: значение выбранного канала копируется в R, G и B, остальные два канала обнуляются (`R = (r, r, r)`, `G = (g, g, g)`, `B = (b, b, b)`).

Вкладка «2. Гистограммы каналов» содержит три гистограммы — по одной на канал, цвет столбцов совпадает с каналом. Каждая гистограмма показывает число пикселей для значений 0–255 соответствующего канала исходного изображения; сумма столбцов равна числу пикселей.

Пункт списка «Сохранить» дополнен вариантами «Канал R», «Канал G», «Канал B».
